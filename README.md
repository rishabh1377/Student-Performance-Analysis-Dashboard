# Student Performance Analysis Dashboard

## Overview

This project is an Excel-based Student Performance Analysis Dashboard created to analyse academic performance, attendance trends, and subject-wise insights using data visualization and reporting techniques.

The dashboard helps in:

* Analysing student marks and attendance
* Identifying top-performing students
* Visualizing academic trends
* Generating insights using charts and Pivot Table based analysis

---

# Tools Used

* MS Excel
* Pivot Tables
* Charts & Graphs
* Conditional Formatting
* Lookup Functions
* Data Cleaning Techniques

---

# Features

* Student dataset management
* Attendance analysis
* Subject-wise performance tracking
* Average marks calculation
* Dashboard visualization
* Top student identification
* Branch-wise distribution analysis

---


# Key Insights

* Students with higher attendance generally achieved better average scores.
* Dashboard visualization improved quick understanding of academic performance.
* Branch-wise comparison helped identify performance distribution.
